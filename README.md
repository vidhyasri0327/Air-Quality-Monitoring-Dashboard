# 🌍 Air Quality Monitoring Dashboard

## 📌 Project Overview
This Power BI dashboard analyzes air quality data across major cities and provides insights into AQI trends, pollution levels, and PM2.5 impact.

## 🛠 Tools Used
- Power BI
- SQL
- Excel

## 📊 Key Features
- Average, Maximum and Minimum AQI KPIs
- City-wise AQI Comparison
- AQI Share by City
- PM2.5 vs AQI Correlation Analysis
- Interactive Slicers
- Key Insights Panel
- AQI Category Classification (CPCB Standards)

## 💡 Key Insights
- Highest AQI: Delhi
- Lowest AQI: Chennai
- PM2.5 impacts AQI
- Average AQI: 238
